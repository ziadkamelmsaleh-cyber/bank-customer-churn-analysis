# Bank Customer Churn Analysis

## 📌 Project Overview
This project analyzes customer churn behavior in a bank using Power BI.

The goal is to identify:
- High-risk customers
- Key churn factors
- Business recommendations to improve retention

---

## 🛠 Tools Used
- Power BI
- SQL
- Data Cleaning
- Data Visualization

---

## 📊 Dashboard Preview

![Dashboard](dashboard.png)

---

## 🔍 Key Insights
- Germany has the highest churn rate
- Female customers churn more than males
- Inactive customers are more likely to leave
- Customers aged 46–60 show high churn behavior

---

## 💡 Recommendations
- Launch retention campaigns in Germany
- Improve engagement for inactive members
- Offer personalized financial products
- Create loyalty programs for high-risk groups
